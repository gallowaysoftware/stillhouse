# CLA signatures

This branch exists only to hold contributor licence agreement signatures.
It has no shared history with `main` and contains no source code.

`signatures/version1/cla.json` is written by the `cla` workflow when a
contributor signs by commenting on their pull request. Don't edit it by
hand, and don't protect this branch — the bot needs to push to it.

The agreement itself is [CLA.md on main](../../blob/main/CLA.md).
